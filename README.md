# ColorFun - 强大的颜色生成插件

🎨 专注于颜色生成与可视化的 AstrBot 插件，提供极其强大的颜色相关功能。

## ✨ 功能特性

- 🎨 **颜色生成** - 生成指定颜色的图片，支持多种颜色格式
- 🌈 **渐变色** - 支持多色渐变生成，多种方向可选
- 🎨 **调色板** - 生成自定义或主题调色板
- 📖 **颜色信息** - 显示 HEX、RGB、HSL 值
- 🎭 **多种样式** - 纯色、渐变、网格、模糊、噪点
- 🌟 **预设主题** - 彩虹、冷色调、暖色调、中性色、自然、科技感、复古、霓虹
- 🔤 **中英双语** - 同时支持中文和英文颜色名称

## 🚀 安装

### 方式一：通过 AstrBot 插件市场安装

1. 打开 AstrBot 管理面板
2. 进入「插件」→「插件市场」
3. 搜索 `ColorFun` 并安装

### 方式二：手动安装

1. 克隆仓库到插件目录：
   ```bash
   cd /path/to/astrbot/data/plugins
   git clone https://github.com/NumInvis/astrbot_plugin_ColorFun.git
   ```

2. 重启 AstrBot

## 📖 使用指南

### 命令列表

#### 🎨 颜色命令

| 命令 | 说明 | 示例 |
|------|------|------|
| `/颜色 <颜色值> [样式]` | 生成颜色图片 | `/颜色 红` |
| `/color <颜色值> [样式]` | 英文命令 | `/color red` |

**支持的颜色格式：**
- 颜色名: `红`、`蓝`、`green`、`yellow`
- 十六进制: `#FF0000`、`FF0000`、`0xFF0000`
- RGB: `rgb(255,0,0)` 或 `255 0 0`
- HSL: `hsl(120, 100%, 50%)`
- 渐变色: `红;黄;蓝` 或 `#FF0000;#00FF00`
- 主题: `彩虹`、`冷色调`、`暖色调`、`中性色`、`自然`、`科技感`、`复古`、`霓虹`

**支持的样式：**
- `solid`: 纯色
- `gradient`: 渐变
- `pattern`: 网格
- `blur`: 模糊
- `noise`: 噪点

#### 🌈 渐变命令

| 命令 | 说明 | 示例 |
|------|------|------|
| `/渐变 <颜色1>;<颜色2>;<颜色3> [方向]` | 生成渐变色图片 | `/渐变 红;黄;蓝` |

**支持的方向：**
- `vertical`: 垂直
- `horizontal`: 水平
- `diagonal`: 对角线

#### 🎨 调色板命令

| 命令 | 说明 | 示例 |
|------|------|------|
| `/调色板 <颜色1>;<颜色2>;<颜色3>...` | 生成颜色调色板 | `/调色板 红;黄;蓝;绿` |
| `/调色板 <主题>` | 生成主题调色板 | `/调色板 彩虹` |

#### ❓ 帮助命令

| 命令 | 说明 |
|------|------|
| `/colorfun帮助` | 显示帮助信息 |

### 使用示例

#### 1️⃣ 生成颜色图片
```
/颜色 红
```
生成红色图片，显示 HEX、RGB 和 HSL 值。

#### 2️⃣ 使用不同样式
```
/颜色 #FF0000 gradient
```
生成带渐变效果的红色图片。

```
/颜色 #00FF00 pattern
```
生成带网格图案的绿色图片。

#### 3️⃣ 渐变色
```
/渐变 红;黄;蓝
```
生成红到黄到蓝的垂直渐变色图片。

```
/渐变 #FF0000;#00FF00;#0000FF horizontal
```
生成红到绿到蓝的水平渐变色图片。

#### 4️⃣ 调色板
```
/调色板 彩虹
```
生成彩虹主题调色板。

```
/调色板 冷色调
```
生成冷色调主题调色板。

## 🎨 颜色格式详解

### 颜色名称
支持中文和英文颜色名：
- 中文: 红、黄、蓝、绿、黑、白、粉、紫、橙、青、棕、金、银...
- 英文: red、yellow、blue、green、black、white、pink、purple、orange、cyan、brown、gold、silver...

### 十六进制
- `#FF0000` - 标准格式
- `FF0000` - 省略#号
- `0xFF0000` - 0x前缀
- `#F00` - 简写格式

### RGB格式
- `rgb(255, 0, 0)` - CSS格式
- `255 0 0` - 空格分隔

### HSL格式
- `hsl(120, 100%, 50%)` - 色相、饱和度、亮度

### 渐变色
使用分号 `;` 或 `；` 分隔多个颜色：
- `红;黄;蓝`
- `#FF0000;#00FF00;#0000FF`

## 🎭 预设主题

| 主题 | 说明 |
|------|------|
| 彩虹 | 彩虹七色渐变 |
| 冷色调 | 蓝色、青色等冷色系 |
| 暖色调 | 红色、橙色等暖色系 |
| 中性色 | 黑白灰棕等中性色 |
| 自然 | 绿色、棕色等自然色 |
| 科技感 | 蓝色、青色等科技感颜色 |
| 复古 | 棕色、米色等复古色调 |
| 霓虹 | 粉色、青色等霓虹色彩 |
