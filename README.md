# ColorFun - 强大的色图生成插件

🎨 专注于颜色生成的 AstrBot 插件，提供纯粹、高清的色图生成功能。

## ✨ 功能特性

- 🎨 **纯色生成** - 生成指定颜色的高清纯色图片
- 🌈 **渐变色** - 支持多色渐变生成
- 🎨 **调色板** - 生成自定义或主题调色板
- 🎲 **随机色图** - 一键生成随机色图，包含多种模式
- 🌟 **预设主题** - 彩虹、冷色调、暖色调、中性色、自然、科技感、复古、霓虹
- 🔤 **中英双语** - 同时支持中文和英文颜色名称
- 📸 **高清输出** - 所有图片均为 800x800 或 800x400 分辨率

## 🚀 安装

### 方式一：通过 AstrBot 插件市场安装

1. 打开 AstrBot 管理面板
2. 进入「插件」→「插件市场」
3. 搜索 `ColorFun` 并安装

### 方式二：手动安装

1. 克隆仓库到插件目录：
   ```bash
   cd /path/to/astrbot/data/plugins
   git clone https://github.com/NumInvis/astrbot_plugin_ColorFun.git
   ```

2. 重启 AstrBot

## 📖 使用指南

### 命令列表

| 命令 | 说明 |
|------|------|
| `/颜色 <颜色值>` | 生成颜色图片 |
| `/色图` | 随机生成一张色图 |
| `/colorfun帮助` | 显示帮助信息 |

### 支持的颜色格式

- **颜色名**: `红`、`蓝`、`green`、`yellow`
- **十六进制**: `#FF0000`、`FF0000`
- **RGB**: `rgb(255,0,0)` 或 `255 0 0`
- **渐变色**: `红;黄;蓝` 或 `#FF0000;#00FF00`
- **主题**: `彩虹`、`冷色调`、`暖色调`、`中性色`、`自然`、`科技感`、`复古`、`霓虹`

### 使用示例

#### 1️⃣ 生成纯色图片
```
/颜色 红
```
生成红色纯色图片。

#### 2️⃣ 使用 HEX 颜色
```
/颜色 #FF0000
```

#### 3️⃣ 使用 RGB 颜色
```
/颜色 255 0 0
```

#### 4️⃣ 生成渐变色
```
/颜色 红;黄;蓝
```
生成红到黄到蓝的渐变色图片。

#### 5️⃣ 生成主题调色板
```
/颜色 彩虹
```
生成彩虹主题调色板。

#### 6️⃣ 随机色图
```
/色图
```
随机生成一张色图，可能是纯色、渐变色或调色板。

## 🎭 预设主题

| 主题 | 说明 |
|------|------|
| 彩虹 | 彩虹七色渐变 |
| 冷色调 | 蓝色、青色等冷色系 |
| 暖色调 | 红色、橙色等暖色系 |
| 中性色 | 黑白灰棕等中性色 |
| 自然 | 绿色、棕色等自然色 |
| 科技感 | 蓝色、青色等科技感颜色 |
| 复古 | 棕色、米色等复古色调 |
| 霓虹 | 粉色、青色等霓虹色彩 |
